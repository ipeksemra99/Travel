# TRAVEL
Bu proje, **HTML** ve **CSS** kullanılarak oluşturulmuş bir "Yunanistan Tatili Temalı Seyahat Web Sitesi" arayüzüdür.

# ÖZELLİKLER
- Yunanistan'da rüya gibi bir tatil için tanıtım bölümleri
- Responsive tasarım
- Modern kullanıcı arayüzü
- CSS ile estetik, yumuşak geçiş efektleri ve görsel vurgular
- Basit ve etkili rezervasyon formu
- Sade, kullanıcı dostu arayüz

  # EKRAN KAYDI

  Travel projemin bir önizlemesi yukarıdaki gifte yer almaktadır.
